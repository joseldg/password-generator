# 🔐 Password Generator Pro

Una herramienta web ligera y segura para generar contraseñas robustas al instante.

### ✨ Características
- 🛡️ **Seguridad:** Generación basada en valores aleatorios criptográficos.
- 🎨 **Interfaz Moderna:** Diseño responsivo con gradientes y animaciones suaves.
- ⚙️ **Personalización total:** Control de longitud (8-50 caracteres) y tipos de símbolos.
- ✍️ **Modo Manual:** Evalúa la fortaleza de tus propias contraseñas en tiempo real.
- 📋 **Copiado rápido:** Botón integrado para copiar al portapapeles con un clic.

### 🚀 Tecnologías
- HTML5 / CSS3 (Variables CSS, Flexbox)
- JavaScript Vanilla (No requiere dependencias externas)
